# P3 — Experiencia de realidad virtual 360º

**Autor:** Andrés Bernal Trujillo

## Descripción

La página contiene dos experiencias panorámicas creadas con A-Frame:

- **Imagen 360º:** utiliza `<a-sky>` para mostrar una fotografía panorámica.
- **Vídeo 360º:** utiliza `<a-videosphere>` para mostrar un vídeo panorámico. Se puede iniciar y pausar con el botón correspondiente.

Los botones permiten cambiar de una experiencia a la otra. Dentro del visor, arrastra con el ratón para mirar en diferentes direcciones. La página incluye estilos CSS sencillos para organizar el contenido y adaptarlo a pantallas pequeñas.

## Cómo abrir el proyecto

1. Descarga y descomprime la carpeta del proyecto.
2. Abre `index.html` en un navegador con conexión a Internet.
3. Prueba los dos botones de las experiencias y el control de reproducción del vídeo.

A-Frame y los recursos multimedia se cargan desde Internet, por lo que es necesaria una conexión activa.
